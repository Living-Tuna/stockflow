ecbills Scanner Bridge

USB barcode/QR capture + quick product portal for the web billing app.

Web App Connection

The portal talks to your ecbills web billing app over this device’s loopback interface. Browsers open on the billing page connect to the WebSocket below and auto-add scanned products.

Service Status

    USB Barcode Scanner

    Enable Scanner Listening, keep this portal window focused, then scan. Each read (scanners send the code followed by Enter) is pushed over the WebSocket to every open billing page, which auto-adds the product. Scans are also logged below.

    Scanner Listening: OFF
    Focus this window, then scan. When the window loses focus, checks the bridge tray menu.
